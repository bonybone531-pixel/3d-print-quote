# 3d-print-quote

3D 列印報價計算機。單一網頁，不需安裝。

**線上版（手機、電腦都能開）：** https://bonybone531-pixel.github.io/3d-print-quote/
推送到 `main` 後約一分鐘會自動更新。本機也可以直接雙擊 `index.html` 使用。

## 功能

- **上傳切片檔自動帶入**：拖曳切片檔，自動讀取克數、列印時間、材料、機型
  - Bambu Studio：直接用「匯出切片檔案」的 `.gcode.3mf`，多盤會每盤各一列
  - 也支援 OrcaSlicer / PrusaSlicer / Cura 的 `.gcode`（Cura 只給長度時依線徑與密度換算克數）
- **機型選擇**：每個列印件可選 H2C / P1S，電費與折舊依該機型計算
- **手動新增**：沒有 G-code 時可直接輸入克數與時數
- **成本計算**（每件 × 數量）
  - 線材費 = 克數 × 每公斤成本
  - 電費 = 時數 × 機型平均功率 × 電價
  - 機台折舊 = 時數 ×（機台價格 ÷ 預估壽命小時）
  - 後處理人工 = 分鐘數 × 時薪
  - 失敗耗損 % 加在線材、電費、折舊上
- **報價**：成本 ×（1 + 利潤加成 %），未達最低消費以最低消費計，再加運費與包裝
- **報價單文字**：一鍵複製，直接貼給客人（只顯示售價，不顯示成本）

## 設定

所有單價、功率、利潤、運費都在頁面最下方「計價設定」修改，會自動存在瀏覽器裡（同一台電腦、同一個瀏覽器下次打開仍保留）。

預設值（請依自己狀況調整）：

| 項目 | 預設 |
|---|---|
| PLA / PETG / ABS / ASA / TPU 每公斤成本 | 600 / 650 / 650 / 800 / 900 |
| H2C | 機台 NT$ 75,000、壽命 5,000 小時、平均 250 W → 折舊 NT$ 15 / 小時 |
| P1S | 機台 NT$ 22,000、壽命 5,000 小時、平均 120 W → 折舊 NT$ 4.4 / 小時 |
| 電價 | NT$ 4 / 度 |
| 後處理時薪 | NT$ 200 / 小時 |
| 失敗耗損 | 10% |
| 利潤加成 | 50% |
| 運費 / 包裝 | NT$ 60 / NT$ 10 |
| 最低消費 | NT$ 100 |
