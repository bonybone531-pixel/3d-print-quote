# 3d-print-quote

3D 列印報價計算機。單一網頁，雙擊 `index.html` 用瀏覽器打開即可使用，不需安裝。

## 功能

- **上傳 G-code 自動帶入**：拖曳切片後的 `.gcode`，自動讀取克數、列印時間、材料
  - 支援 Bambu Studio / OrcaSlicer / PrusaSlicer / Cura
  - Cura 只提供線材長度時，會依線徑與材料密度換算成克數
  - Bambu 的 `.gcode.3mf` 需先在切片軟體「匯出 G-code」成純 `.gcode`
- **手動新增**：沒有 G-code 時可直接輸入克數與時數
- **成本計算**（每件 × 數量）
  - 線材費 = 克數 × 每公斤成本
  - 電費 = 時數 × 功率 × 電價
  - 機台折舊 = 時數 × 每小時折舊
  - 後處理人工 = 分鐘數 × 時薪
  - 失敗耗損 % 加在線材、電費、折舊上
- **報價**：成本 ×（1 + 利潤加成 %），未達最低消費以最低消費計，再加運費與包裝
- **報價單文字**：一鍵複製，直接貼給客人（只顯示售價，不顯示成本）

## 設定

所有單價、功率、利潤、運費都在頁面最下方「計價設定」修改，會自動存在瀏覽器裡（同一台電腦、同一個瀏覽器下次打開仍保留）。

預設值（請依自己狀況調整）：

| 項目 | 預設 |
|---|---|
| PLA / PETG / ABS / ASA / TPU 每公斤成本 | 600 / 650 / 650 / 800 / 900 |
| 印表機平均功率 | 150 W |
| 電價 | NT$ 5 / 度 |
| 機台折舊 | NT$ 10 / 小時 |
| 後處理時薪 | NT$ 200 / 小時 |
| 失敗耗損 | 10% |
| 利潤加成 | 50% |
| 運費 / 包裝 | NT$ 60 / NT$ 10 |
| 最低消費 | NT$ 100 |
